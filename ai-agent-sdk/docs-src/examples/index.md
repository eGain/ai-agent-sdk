# Examples

Use these samples as a starting point when you wire the SDK into your app. They show authentication, connecting to an agent, and sending messages in **browser** and **Node.js** environments.

Clone or open the repo and run the projects under `usage-examples` (see each folder’s README for credentials and setup):

[View usage-examples on GitHub](https://github.com/eGain/ai-agent-sdk/tree/master/ai-agent-sdk/usage-examples)
