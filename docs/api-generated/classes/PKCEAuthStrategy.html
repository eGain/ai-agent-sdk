logout ​

▸ logout(): Promise<void>

Log out via MSAL using the same scheme as login. Popup omits state and uses redirectUri?logout=true. Redirect passes hash-stripped nextRoute as state so auth-redirect.html can bounce back. MSAL clears its own cache — do not call clearCache / removeAccount here. If MSAL throws, navigate to the JWT logout claim, else end_session_endpoint.
