updateScopes ​

▸ updateScopes(scopes, deploymentInfo?): Promise<void>

Replace the scopes the current strategy will use for its next token request, without re-running initialization. Used once agent details reveal per-agent extraScopes for an agent that stays on the anonymous strategy. Strategies that do not implement updateScopes (PKCE, pre-auth) are left untouched.
